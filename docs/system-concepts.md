# System Concepts: provenance and limits

This page incorporates ideas from Codex research chat `01a1d77e-6fa8-7c01-82a4-ca42dc8847c0` into a separate MORS AEGIS copy.

## Included

- **HARBOR perimeter observation concept:** the chat described a Blender gallery with 41 GLB models and a proposed HARBOR perimeter sensor ring. In that work, a ring-to-hood intersection was still reported by Blender BVH inspection. Therefore, the web page uses a simple interactive SVG reconstruction to communicate the concept. It is not the original CAD, not dimensionally accurate, and does not claim fit or clearance.
- **Extinction-pathway map:** a 2D conceptual map organizes candidate experimental variables around oxygen availability, forced flow, heat transfer, and fuel boundary conditions. It does not claim that changing any one variable will extinguish a fire. A controlled experiment would need a protocol, calibrated sensors, safety review, repeat trials, and analysis.
- **Evidence boundaries:** NASA references motivate questions only. NASA did not test or endorse the MORS concepts shown here. PSI-69 droplet burning-rate data do not establish solid-material behavior or validate these system concepts.

## Provenance

The referenced chat also described PULSE-MIST, VAPOR-TRACE, a proposed extinction-pathway experimental protocol, and an exported Blender gallery. Their source models and project files were not present in the local checkout used for this backup. They are not recreated here or claimed as downloadable assets. This page links to the NASA sources already used by the main project and to the NASA NTRS SoFIE-GEL record [20240007628](https://ntrs.nasa.gov/citations/20240007628) as scientific context, not as validation of the concepts.
