# 3D concept archive

This folder contains 41 GLB concept models, the Blender gallery, its overview image, and a SHA-256 manifest. The interactive site viewer uses the GLB files directly; Blender users can open `FLAME-IN-FREEFALL-3D-GALLERY.blend`.

All items are conceptual research artifacts. They are not manufacturing drawings or qualified hardware. See the method notes in `methods/` and the clearance report before interpreting HARBOR geometry.
